# 部署手册 —— 从零到跑通

> 目标读者：要在一台新 Mac 上复现这套系统的你。
> 按顺序执行即可；每一步都标了"验证点"。OpenClaw 侧的细节见 [`DEPLOY.md`](DEPLOY.md)。

---

## 0. 前置条件

| 组件 | 用途 | 必需？ |
|---|---|---|
| macOS（Apple Silicon 优先，建议 ≥24GB 内存） | 宿主 | 是 |
| Python 3.10+ | 引擎（纯标准库，**零第三方依赖**） | 是 |
| [OpenClaw](https://github.com/rubencou/claw) | 角色 agent（"脑"） | 是（接入时） |
| Ollama（+ 本地 Qwen MoE 模型） | 本地大模型（直聊走本地，敏感内容不出机） | 推荐 |
| 微信 bot 渠道（openclaw-weixin） | 主投递渠道 | 是（生产） |
| ComfyUI | 本地生图（亲密度到阈值后绕开云端审核） | 可选 |
| VTube Studio | Live2D 表情同步 | 可选 |

## 1. 五分钟跑通演示（不需要 OpenClaw）

```bash
# 纯引擎：场景状态机 + 事件生成 + 控制台投递，不连任何外部服务
python3 main.py --once --ticks 60 --seed 7 --user-idle-min 150
```

**验证点**：控制台能看到"第 N 天 HH 点 · 天气 · 地点 · 在场 NPC · 生成事件 · 投递结果"。
这就是需求 ⑥（纯逻辑数字化场景 + 随机事件）的最小可运行证明。

## 2. 部署 OpenClaw 与角色人设

1. 安装 OpenClaw，确认 `openclaw --version` 可用；`openclaw gateway` 默认监听 `127.0.0.1:18789`。
2. 建 agent `main`（胡桃）。
3. 把人设同步到 OpenClaw 工作区（`~/.openclaw/workspace/`）：

```bash
cp persona/SOUL.md      ~/.openclaw/workspace/SOUL.md
cp persona/IDENTITY.md  ~/.openclaw/workspace/IDENTITY.md
cp persona/USER.md      ~/.openclaw/workspace/USER.md
# MEMORY.md 是私人的（生日/账号/昵称），先复制模板再填
cp persona/MEMORY.md.example ~/.openclaw/workspace/MEMORY.md
#   ↑ 然后把里面的 <...> 占位符替换成你自己的信息
```

4. 配置 OpenClaw 侧的心跳 / Gateway Hooks —— 按 [`docs/DEPLOY.md`](DEPLOY.md) 逐条做。

---

## 3. 选投递路线，填配置占位符

三条路线对应三个配置；先只跑一条，推荐 **sessions（生产主链路）**：

```bash
cp config.sessions.json  config.sessions.local.json
```

编辑 `config.sessions.local.json`，把下面这些占位符换成你的真实值：

| 占位符 | 含义 | 在哪填 |
|---|---|---|
| `YOUR_WECHAT_OPENID` | 你本人的微信 openid（`<openid>@im.wechat`） | `reply_to`、`security.weixin_owner_ids` |
| `YOUR_BOT_ACCOUNT` | 微信 bot 账号 id（形如 `xxxx-im-bot`） | `reply_account` |
| `YOUR_ACCOUNT` | 你的 OpenClaw 会话账号名（`direct:<名>`） | `user_session_key` |

> 其余字段（气泡节奏、生图参数、压缩阈值、亲密度切换阈值等）都有内联注释说明，
> 见配置里的 `_调参指引` / `_note` / `_output_note` 等键——**改参数不用动代码**。

## 4. 常驻运行 + 日志

```bash
# 前台跑（先验证几轮）
python3 main.py --config config.sessions.local.json

# 后台常驻（引擎自带守护：异常退出自动重启，指数退避 5s→300s）
nohup python3 main.py --config config.sessions.local.json > logs/engine.out 2>&1 &

# 运行日志 WebUI（另一个终端）
python3 log_server.py        # http://127.0.0.1:8620/   模型调用: /models
```

**验证点**：
- 引擎日志里出现 `[loop] 第 N 天 … 好感度=… 档位=…`；
- 微信收到胡桃**主动**发来的转述见闻（不是一问一答）；
- WebUI 能看到事件 / 投递 / 回执记录。

## 5. 可选组件

| 组件 | 命令 | 说明 |
|---|---|---|
| 本地大模型 | Ollama 拉取模型 → `openclaw.json` 里 agent `main` 的 `model.primary` 设为 `ollama/<模型>` | 直聊走本地；云↔本切换见 §5 |

## 7. 本机路径假设（换机器时必查）

代码里有一批 `~` 开头的**默认路径**，换机器 / 换目录时要对一下：

| 文件 | 硬编码路径 | 说明 |
|---|---|---|
| `scene/delivery.py` | `~/Documents/DSH/hutao/gallery` | 图库白名单（`[[img: 路径]]` 校验用） |
| `scene/delivery.py` | `~/ComfyUI-Installs`、`~/Thunder-TTS/scripts/hutao_tts.sh` | 本地生图/语音默认位置 |
| `tools/verify_all.py` | `~/ComfyUI-Installs/ComfyUI`、`~/ComfyUI-Shared/models/checkpoints`、`~/Thunder-TTS/scripts/hutao_tts.sh` | 体检脚本探测路径 |
| `scene/security.py` | `~/.openclaw/openclaw-weixin/accounts/*-im-bot.context-tokens.json`（glob）+ 回退 `YOUR_BOT_ACCOUNT` | 发送者名单文件 |

> 这些是"本机默认值"而非机密；把仓库放在别处时，优先改 `scene/delivery.py` 的图库白名单，
> 其余按实际安装位置调整即可（`verify_all.py` 会如实报告哪些探测失败）。

## 8. 常见问题

- **她今天怎么没说话？** 先看 `logs/engine.out` 引擎是否在跑、有无异常；再看 WebUI 投递/回执；
  微信渠道要求用户**最近约 30 分钟内互动过**才能主动发（平台限制，见 `DEPLOY.md`）。
- **模型被降级/输出退化？** 只看 `model.fallback_step` 轨迹事件，别信会话里的 `message.model`。
- **复读 / 起手式重复？** 看 `docs/直聊复读排查.md`；`style_rewrite`（仅生产配置默认开）会周期性剥离历史回复开头的括号动作。
- **对话中途冒见闻？** `decision.conversation_buffer_minutes`（默认 20）与 `news_hold_minutes`（默认 60）两道闸。
